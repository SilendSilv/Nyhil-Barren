Nyhil-Barren will be a Black-Metal inspired icon pack which will fork from Papirus in the beginning (check AUTHORS for more information),
for people that are tired of the conventional Coffee-Esque vibes or Vaporwave adjacent "rices".
Right now this is a solo project by yours truly- Silend or SilendSilv that will once i'll leave system icon purgatory include custom
icons for your beloved apps (E.g: Steam, Firefox, Ghostty).

This is a prototype README, things can and will change once the project grows.

Install: currently no installation tutorial as its still a thought, altough once the Project grows it will have a clear installation tutorial and how to set it up,

Includes: it is planned to be an Icon Pack, that means things like your Settings icon, or Sound icon will be changed, however no deep themes like how Folders look like inside Dolphin or similar.
This could be added in the future but dont count on my motivation cycle to be planning this in right now
